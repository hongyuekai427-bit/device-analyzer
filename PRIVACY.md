# Privacy Policy

## Our Commitment

Device Intelligence is built with privacy as a core feature, not an afterthought.

## What We Do

- Process all diagnostic data **locally in your browser**
- Never send any data to external servers
- Never use analytics, tracking pixels, or advertising
- Never require an account or API key
- Never store data without your explicit consent

## What We Don't Do

- ❌ Upload device information
- ❌ Send microphone or camera data anywhere
- ❌ Transmit location data
- ❌ Create persistent fingerprints
- ❌ Use third-party scripts
- ❌ Track your browsing behavior
- ❌ Sell or share any information

## Permission Handling

Some diagnostics require browser permissions (camera, microphone, location, etc.):

- Permissions are **never requested automatically**
- Each permission request is preceded by an explanation
- You must explicitly click a button to trigger the request
- Media tracks are stopped immediately after testing
- Location data can be cleared at any time
- All data from permission-gated APIs stays in your browser

## Data Storage

- By default, **no data is persisted**
- If you enable "Remember my last report," data is stored only in your browser's localStorage
- You can clear all local data at any time
- No data is ever sent to any server

## Export

When you export a report:
- The file is generated locally in your browser
- You control where the file is saved
- Sensitive fields are excluded by default
- You can customize what's included in exports

## Third Parties

This application uses **zero** third-party services:
- No analytics (no Google Analytics, no Plausible, etc.)
- No CDN resources (everything is bundled)
- No tracking pixels
- No advertising SDKs
- No social media widgets

## Open Source

This application is open source. You can inspect every line of code to verify our privacy claims.

## Contact

If you have questions about privacy, please open an issue on the GitHub repository.
